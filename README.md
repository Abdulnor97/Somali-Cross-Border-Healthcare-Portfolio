# 🩺 Somali Cross-Border Healthcare Spending Analysis

Welcome to the official repository for the **Somali Cross-Border Healthcare Spending** project. This analytical portfolio explores overseas healthcare expenditures, patient volume trends, and financial distributions based on **31,285+ verified records**.

## 🌟 Featured Project Overview

An in-depth investigation into cross-border medical expenditures and patient travel patterns across key destination corridors.

* **Key Impact:** Analyzed over **$219M** in overseas patient spending across top medical hubs (India, Türkiye, Ethiopia, Egypt).
* **Stack:** Power BI, Power Query, Excel Data Modeling, DAX.

## 📌 Conclusion

This project uses real, verified data from over 31,000 patient records to analyze more than $219M in healthcare spending. It shows how raw data can be turned into clean data models, clear financial insights, and easy-to-use dashboards for decision-makers.
